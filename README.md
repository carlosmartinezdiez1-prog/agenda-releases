# Agenda · instaladores

Aquí solo se publican los **instaladores de Agenda** para Windows 11 y el archivo `latest.json`, que usa el actualizador automático. No hay código fuente ni datos personales.

- Cada versión se compila y se prueba en este repositorio con `.github/workflows/build.yml`, que solo se lanza a mano.
- Las versiones con actualización automática van firmadas: la app comprueba la firma antes de instalar nada.
